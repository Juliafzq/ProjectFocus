# Project Focus (Fable / Flow)

> A tactile, digital-analog tool space on iOS that increases a user's sense of lived fulfillment by restoring daily focus, accomplishment, and presence without coercive gamification, complex hierarchies, or productivity guilt.

## About

**Fable / Flow** bridges the divide between fragmented productivity app stacks and overwhelming all-in-one dashboards by delivering a calm, hyper-minimalist, physical-first environment built around two tactile objects:
1. **A Dual-Sided Index Card** (White Front for up to 6 daily tasks with Left-to-Right graphite pencil strikethrough/erase; Matte Black Back for evening reflection with auto-scaling typography and up to 2 compressed photos).
2. **A 3D Heirloom Tomato Pomodoro Timer** (`2×2` 4-Tomato Grid and Single Big Hero Tomato with a bidirectional 180-minute 3-turn odometer dial and forward-rotating Stopwatch mode).
